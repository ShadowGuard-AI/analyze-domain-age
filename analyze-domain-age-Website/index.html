Panel one: what the tool returns

analyze-domain-age determines the age of a domain name by means of WHOIS lookups, using the python-whois library. On success it prints four things, set here as four tile rows:

The domain. Its creation date. The current date. The age in days.

That quartet is the entire promise. No registrar history, no expiry reporting, and no ownership details are added, because the README never mentions them.

Panel two: arrival and departure

git clone https://github.com/ShadowGuard-AI/analyze-domain-age
cd analyze-domain-age
pip install -r requirements.txt
python3 main.py DOMAIN [-o OUTPUT] [-v]

The one example domain the README itself supplies in its parameter notes is example.com.

Panel three: the flag tiles

DOMAIN: the domain name to analyze.

-h, help: shows the help message and exits.

-o or --output: an optional output file that saves results in CSV format.

-v or --verbose: enables verbose logging.

With -o, the result is written as one CSV row carrying the same four values the terminal prints: domain, creation date, current date, and age in days.

Panel four: the two closed gates

A domain without a dot is rejected and the program exits with code 1.

A failed WHOIS lookup also exits with code 1.

In this station a refusal is part of the timetable, not an accident.

Panel five: the notice by the shuttered window

Live run not possible in this environment: the whois package is not installed here and installs are not permitted in this wave, and a live WHOIS lookup is outside the allowed network hosts. The parameter list above is taken from the argument parser in main.py, and the file compiles cleanly.

This site keeps that notice visible instead of implying a demonstration that never happened.
