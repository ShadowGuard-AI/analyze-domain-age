The Strata Section

Determines the age of a domain name using WHOIS lookups with the python-whois library. A domain, like a cliff band, carries its age in the layer where it was laid down; this tool reads the creation date off the record and counts the days.

View on GitHub Read the README

Prints: the domain, its creation date, the current date, and the age in days.
With -o: one CSV row with the domain, creation date, current date, and age in days.
Requirements: pandas>=2.2.0 and python-whois.
Licence: MIT License, see LICENSE in the repository.

Usage

python3 main.py DOMAIN [-o OUTPUT] [-v]

Parameters

ParameterWhat the README says
DOMAINThe domain name to analyze, for example example.com.
-hShow help message and exit.
-o, --outputOptional output file to save results in CSV format.
-v, --verboseEnable verbose logging.

Verified behavior

  • On success the tool prints the domain, its creation date, the current date, and the age in days.
  • A domain without a dot is rejected and exits 1.
  • A failed WHOIS lookup exits 1.
  • With -o, the result is written as one CSV row with the domain, creation date, current date, and age in days.

Stated limits

Live run not possible in the documenting environment: the whois package is not installed there and installs are not permitted in that wave, and a live WHOIS lookup is outside the allowed network hosts. The parameter list above is taken from the argument parser in main.py, and the file compiles cleanly. The two refusal cases stand in the open: a domain without a dot exits 1, and a failed WHOIS lookup exits 1.
